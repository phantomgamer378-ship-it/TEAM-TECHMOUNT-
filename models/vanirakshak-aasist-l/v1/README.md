# VANIRAKSHAK AASIST-L (v1)

This is the packaged v1 model artifact for VANIRAKSHAK.
It has been structured per Phase 2 requirements to isolate the ML assets from the inference and training backend.

**Contents**:
- `model.pt`: Fine-tuned PyTorch state_dict (AASIST-L)
- `config.yaml`: Network architecture config
- `preprocessing.yaml`: Explicit audio preprocessing requirements
- `metadata.json`: Model provenance and metrics
- `metrics.json`: Test-set evaluation results
